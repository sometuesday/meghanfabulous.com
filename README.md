# meghanfabulous.com

A temporary coming-soon page. Netlify publishes the `site/` directory. The full redesign lives on `cursor/editorial-retrospective-bdea` and is a separate pull request.

## What is published

`site/` is a static page: one lookbook photograph, a short announcement, and a Netlify Form named `launch-notify`. Old URLs redirect to this page with a temporary 302. `/thank-you` is the form’s success page and is excluded from that catch-all. `site/404.html` is the 404 fallback.

## Archive

`archive/2026-09-30-original-site/` is the site as it stood on 30 September 2026. It stays in the repository for reference. It sits outside the Netlify publish directory, so it is not publicly served.

- `archive/2026-09-30-original-site/site/` — the served HTML, assets, and 404
- `archive/2026-09-30-original-site/content.md` — the visible copy
- `archive/2026-09-30-original-site/review.md` — a review of that site
- `archive/2026-09-30-original-site/screenshot-desktop-1440.png` and `screenshot-mobile-390.png`
